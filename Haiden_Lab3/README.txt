# Simple Calculator

## Description
A simple C++ console program that calculates an output from an operator and two separate numbers, before displaying the mathematical expression along with the result.

## How to Run
1. Open the project folder in Visual Studio.
2. Press Ctrl+F5 to build and run.
3. Input as prompted.

## Sample Input / Output
Input:
	Input choice: 3
	Input first number: 6
	Input second number: 2
Output:
	Result: 6 * 2 = 12
